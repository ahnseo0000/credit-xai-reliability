# L5 최소판: 승인·거절 기대손익과 경계 구간 비중

> **외부 가정, 실제 수익이 아님, 탐색적.** 금리·부도시손실률·비용률은 모두 외부 가정이고 데이터에서 구한 값이 아니다. 대출액은 1로 정규화했다. 해석 문장 없이 숫자와 표만 적는다.

## 입력과 정의

- 확률: v2 동결 모형(K=100)의 **valid** 예측 PD, 46,127건 (test 미사용). 실제 부도율 0.0807, 평균 PD 0.0802. 보정 없음.
- 기대손익(승인 시) = (1−PD)·r·A − PD·LGD·A − c·A, A=1. 거절하면 0. 승인 ⇔ 기대손익 > 0 ⇔ PD < (r − c)/(r + LGD) (손익분기 금리 (PD·LGD + c)/(1−PD) < r 과 같다). 이 PD를 '최적 컷오프'라 부른다.
- 실현 손익 = (1−y)·r·A − y·LGD·A − c·A (y = valid의 실제 부도 여부). 같은 외부 가정으로 계산한 참고값이다.
- 임시 컷오프: 0.119124 (사전등록, test PD q80의 고정값). pd ≥ 컷오프면 거절. valid에서 승인율 79.92%.
- 경계 구간: 0.082282 ≤ PD < 0.1948 (q70~q90, 표본 설계의 고정값). valid에서 이 구간의 신청자 비율 **20.74%** (9,565명). 참고: valid 자체 분위수는 q70 0.0835, q80 0.1195, q90 0.1919.
- 파라미터: r ∈ (0.1, 0.15, 0.2), LGD ∈ (0.45, 0.6, 0.75), c ∈ (0.02, 0.04) (18개 조합, 모두 외부 가정).
