# Phase 2 비교: v2 GBM vs WoE 스코어카드 (valid)

- valid 46,127건, 부도율 0.0807. test는 읽지 않았다. 스코어카드의 구간화·WoE·계수는 train에서만 적합했고 valid는 평가에만 썼다 (C는 train 5-fold CV).
- v2 GBM은 K-sweep에서 저장한 K=100 모형의 valid 예측이다 (조기 종료에 valid를 썼으므로 GBM 쪽은 valid에 약간 유리하다). 두 모형 모두 연령·성별 제외, 가중치 없음.
- 스코어카드 변수 25개는 shortlist.csv에서 고른 후보이고, 선택에 부트스트랩 안정성(L2, test SHAP 기반) 참고가 일부 들어갔다 (RUNLOG 참고).
