## 0. 이 문서에 대하여

v1 제안서와, 11월 초 작성된 축소 태스크 목록을 통합해 재설계한 문서다.
v1에서 깎인 것 중 핵심을 복원하고, 축소판에서 개선된 것을 유지하며,
v1에도 없던 **의사결정 계층**을 신규로 추가했다.

각 태스크에 상태를 표시한다.

- `[유지]` 축소판에 있고 그대로 간다
- `[복원]` v1에 있었으나 축소판에서 빠졌고, 되살린다
- `[신규]` v1과 축소판 모두에 없다
- `[보강]` 축소판에 있으나 내용을 키운다

## 1. 프로젝트 정의

### 1.1 핵심 질문

> 설명의 신뢰도는 의사결정의 어느 지점에서 무너지며,
> 그 비용은 승인 전략과 공정성에 어떻게 남는가

### 1.2 연구 질문

| | 질문 | 상태 |
|---|---|---|
| RQ1 | LLM이 언급한 주요 변수가 SHAP 상위 기여 변수와 얼마나 일치하는가 | 유지 |
| RQ2 | 관측된 일치도가 우연 수준을 유의하게 넘어서는가 | 유지 |
| RQ3 | 일치도와 불일치 유형이 집단별로 어떻게 다른가 | 유지 |
| RQ4 | 집단 간 예측확률 분포와 승인율에 공정성 이슈가 있는가 | 유지 |
| **RQ5** | **컷오프 근처에서 설명 신뢰도가 더 낮은가** | **신규** |
| **RQ6** | **LLM이 법적으로 사용 불가한 사유를 언급하는 비율은 얼마이며 집단별로 다른가** | **신규** |
| **RQ7** | **설명 신뢰도에 따른 라우팅 정책의 비용과 효과는 얼마인가** | **신규** |

### 1.3 v1 대비 변경 요약

**유지한 v1 설계**
다중 XAI 교차 비교, faithfulness 기반 reference 채택, 부트스트랩 CI,
LLM 일치도 RQ1~RQ4, 순열검정, 불일치 4유형, 프롬프트·모델 개입 실험,
공정성 분석, BH 보정, 웹 서비스, LangGraph.

**축소판에서 유지할 개선**
확률 보정, 교란 통제 로지스틱 회귀, Cohen's kappa 수동 검증,
편향 전이형 판정 로직, SMOTE 제거.
SMOTE는 확률 분포를 왜곡해 보정과 충돌하므로 복원하지 않는다.
MICE도 복원하지 않는다. 트리 모델에서 결측은 그 자체가 신호다.

**폐기**
CreDB 금융빅데이터개방시스템, 공공데이터포털.
신청 절차가 일정에 맞지 않고, Home Credit의 보조 테이블이 같은 역할을 한다.

**신규**
0층 전체, 1층 구간화·스코어카드·신용 검증 지표, 2층 반사실·설명 안정성,
3층 품질 다차원화·통지서 양식, 4층 RQ5·RQ6, 5층 전체, 6층 거버넌스.

## 3. 층별 설계

### L0. 신용 데이터 구축

**목적** 신청서 한 장이 아니라 신용 행태를 가진 사람을 만든다.

**사용 테이블**

| 테이블 | 행 수 | 내용 |
|---|---|---|
| application_train | 307K | 현재 신청 |
| bureau | 1.72M | 타 기관 여신 |
| bureau_balance | 27M | 타 기관 월별 상태 |
| previous_application | 1.67M | 과거 신청과 승인·거절 |
| installments_payments | 13.6M | 실제 상환 이력 |
| credit_card_balance | 3.8M | 카드 월별 소진율 |
| POS_CASH_balance | 10M | 할부·현금 월별 |

**태스크**

- `[신규] L0-1` 보조 테이블 6종 다운로드, 공유 드라이브 적재
- `[신규] L0-2` SK_ID_CURR 기준 집계 파이프라인 설계. SQL로 작성
- `[신규] L0-3` 피처 생성 — 유형별
  - A 상환능력: 연금/소득, 대출액/소득, 대출액/연금, 1인당 소득, 대출액/담보가, 타기관 연금 합산 부담률
  - B 신용이력: 최초 개설 경과일, 활성·종료 계좌 수와 비율, 상품 종류 수
  - C 연체: 현재 연체일수 max, 연체 계좌 수, 최대 연체금액, bureau_balance STATUS 기반 최근 3·6·12개월 최악 등급과 DPD30·60·90 횟수, 연체 추세, installments 실제 연체일 평균·최대·비율, 부분상환 비율
  - D 소진율: bureau DEBT/SUM, 카드 월별 소진율의 평균·최대·최근값·기울기·변동성, 현금서비스 비중, 최소결제 반복 패턴
  - E 신청행태: 신용조회 건수 6종, 과거 거절 비율, 신청 빈도, 요청액 대비 승인액, 신청 간격 추세
  - F 안정성: 근속/나이, 등록·신분증·전화번호 변경 경과일
  - G 외부점수: EXT_SOURCE 평균·최소·최대·곱·결측 개수
  - H 결측구조: 행별 결측 개수, 제출 문서 개수
- `[신규] L0-4` 변수 사전 갱신. 한국어 설명 포함, LLM 단계에서 재사용
- `[신규] L0-5` 단변량 IV 계산. 0.02 미만 제거, 0.5 초과는 누수 의심으로 개별 조사
- `[신규] L0-6` 상관·VIF 제거
- `[신규] L0-7` 분할 간·집단 간 PSI로 안정성 확인
- `[유지] L0-8` 집단 변수 보관: 성별, 연령 구간, 소득 분위. 모델 입력에서는 제외

**완료 기준** 선별 후 변수 80~150개, 변수 사전 완비, IV 표 산출.

### L1. 모형 개발

**목적** 금융권 표준 절차를 따른 신용평가 모형 두 벌.

**태스크**

- `[유지] L1-1` EDA: 부도율, 결측 비율, 분포
- `[유지] L1-2` 전처리: 범주형 인코딩, 결측 표시, 이상치 처리 (DAYS_EMPLOYED 365243 등)
- `[유지] L1-3` 7:1.5:1.5 층화 분할, 시드 고정
- `[신규] L1-4` 구간화. optbinning으로 최적 구간, 단조 WoE 강제, 결측은 별도 구간
- `[보강] L1-5` 챔피언: WoE 로지스틱. 계수·방향·Wald 검정, VIF
- `[신규] L1-6` 점수 환산. 기준점수 600, PDO 20, odds 50:1
- `[보강] L1-7` 챌린저: LightGBM 또는 XGBoost. Optuna + 5-fold 층화 CV
- `[유지] L1-8` 확률 보정. isotonic과 Platt 비교, Brier로 선택
- `[보강] L1-9` 검증 지표
  - 변별력: AUC, KS, Gini, 십분위 lift, 등급별 부도율 단조성, 역전 검증
  - 보정: Brier, ECE, Hosmer-Lemeshow, 보정곡선
  - 안정성: score PSI, characteristic PSI
  - 비교: 부트스트랩 AUC 차이 신뢰구간
- `[유지] L1-10` 모델·전처리 객체 저장

**하지 않는 것** 앙상블·스태킹. 설명가능성이 목적인 프로젝트와 모순된다.

**완료 기준** 두 모형의 지표표, 보정곡선, 점수표 산출.

### L2. 근거 산출과 그 정당화

**목적** 무엇이 영향을 줬는가에 더해, 어떻게 하면 통과하는가까지.

**태스크**

- `[유지] L2-1` 테스트셋 전체 TreeSHAP
- `[유지] L2-2` 전역 요약: mean|SHAP| 순위, summary plot, dependence plot
- `[유지] L2-3` XGBoost 내장 FI
- `[유지] L2-4` Permutation Importance
- `[유지] L2-5` 기법 간 Spearman 순위상관, 엇갈리는 변수 원인 메모
- `[유지] L2-6` 상위 변수 PDP
- `[유지] L2-7` SHAP 부트스트랩 B=50~100, 변수별 95% CI
  - v1은 B=1,000이었다. 시간이 허락하면 상향
- `[유지] L2-8` CI 폭과 중요도의 관계
- `[복원] L2-9` **Faithfulness.** deletion/insertion AUC로 SHAP·FI·Permutation 비교.
  가장 충실한 기법을 L3의 reference로 채택.
  이것이 없으면 "왜 SHAP을 정답으로 삼는가"에 답할 수단이 없다
- `[신규] L2-10` **반사실·recourse.** 승인 쪽으로 넘어가는 최소 변경 조합.
  변경 가능성 제약: 나이·성별 불가, 연체 이력은 시간 필요, 소득은 비용 큼.
  제36조의2 제2항 대응
- `[신규] L2-11` **설명 안정성.** 피처 미세 섭동 시 SHAP 상위 순위 변동.
  L2-7이 학습 데이터 변동 불확실성이라면 이것은 입력 변동 불확실성
- `[신규] L2-12` EXT_SOURCE 제거 ablation
- `[보강] L2-13` L3용 샘플 추출. **부도확률 구간 × 집단 층화, 컷오프 근처 과표집.**
  기존 집단 단독 층화로는 RQ5와 L5가 불가능하다
- `[선택] L2-14` SHAP interaction values

**완료 기준** reference 기법 확정, 300건 CSV 반출, 반사실 산출.

### L3. 설명 생성

**목적** 법정 통지서 형태의 설명을 받고, 생성 조건을 실험한다.

**태스크**

- `[유지] L3-1` LLM 호출 함수: 재시도, 호출 간격, temperature 0, 캐싱
- `[보강] L3-2` 프롬프트
  - 본 실험 2조건: SHAP 미제공 / 제공
  - `[복원]` 파일럿: 프롬프트 3종 × 모델 2종, 50건
- `[보강] L3-3` 출력 스키마 — 제36조의2 제1항 4요소 대응
  - 평가 결과
  - 주요 판단 기준 상위 4개, 영향 방향 포함
  - 사용된 기초정보 개요
  - `[신규]` 개선 방향 (L2-10 반사실과 대조용)
  - 목록 밖 요인 자유 필드 (환각 측정용, 제거하지 않는다)
- `[유지] L3-4` 변수 사전 대조 매칭, 환각 후보 표시
  - `[복원]` 임베딩 유사도 매칭 보강
- `[유지] L3-5` 가짜 SHAP으로 10건 시험, 스키마 위반·파싱 실패율
- `[유지] L3-6` 실제 300건 × 2조건 실행
- `[신규] L3-7` 자기일관성: 동일 입력 3회 반복, 사유 변동 측정
- `[유지] L3-8` 결과 통합 표 저장

**완료 기준** 600건 본 실험 + 300건 파일럿 결과 표.

### L4. 설명 검증

**목적** 설명 품질을 여섯 축으로 측정한다.

| 축 | 측정 | 상태 |
|---|---|---|
| 충실성 | SHAP 상위와의 순위상관, 겹침 비율, 방향 일치율 | 유지 |
| 규제 준수 | 성별·연령·지역을 사유로 언급하는가 | 신규 |
| 사실성 | 설명 속 수치가 실제 피처값과 일치하는가 | 신규 |
| 실행가능성 | 변경 불가 변수만 사유로 드는가 | 신규 |
| 자기일관성 | 반복 호출 시 사유 변동 | 신규 |
| 완전성 | 제36조의2 4요소를 모두 담는가 | 신규 |

**태스크**

- `[유지] L4-1` 샘플별 일치도 지표. 미언급 변수는 최하위 동순위
- `[유지] L4-2` 순열검정 B=1,000
- `[유지] L4-3` 조건 비교: Wilcoxon 부호순위
- `[복원] L4-4` 파일럿 격자 조건 간 비교: 이원분산분석
- `[유지] L4-5` 불일치 4유형 규칙 분류기: 누락형, 순위 역전형, 환각형, 편향 전이형
- `[유지] L4-6` 무작위 50건 수동 라벨링, Cohen's kappa
- `[유지] L4-7` 유형별 빈도표, 조건별 비교
- `[유지] L4-8` 집단 × 불일치 유형 카이제곱
- `[유지] L4-9` 교란 통제 로지스틱: 불일치 ~ 집단 + SHAP 집중도 + 부도확률
- `[유지] L4-10` 편향 전이형 판정
- `[유지] L4-11` 집단별 승인율 차이, 집단 간 예측확률 KS
- `[신규] L4-12` **RQ5.** 부도확률 구간별 일치도. 컷오프 근처 저하 여부.
  SHAP 집중도를 매개로 하는 경로 확인
- `[신규] L4-13` **RQ6.** 보호변수 언급률. 조건별·집단별 비교
- `[신규] L4-14` 효과크기 보고, 사전 검정력 점검
- `[유지] L4-15` BH 보정 α=0.05, 최종 결과표

**완료 기준** RQ1~RQ6 결과표.

### L5. 의사결정

**목적** 확률을 승인·금리·한도로 바꾸고 돈으로 평가한다.

**손익 구조**

```
기대손익 = (1 − PD) · r · A  −  PD · LGD · A  −  c · A
손익분기 금리 = (PD · LGD + c) / (1 − PD)
기대손실(Basel) = PD × LGD × EAD
```

`r` 금리, `A` 대출액, `c` 비용률, `LGD` 부도시손실률.
모두 외부 가정이므로 코드 상단 파라미터로 분리하고 민감도로 범위를 보인다.
실제 수익이라고 주장하지 않는다.

**태스크**

- `[신규] L5-1` 손익 함수 구현, 가정 파라미터 분리
- `[신규] L5-2` 컷오프 스윕: 승인율·불량률·수익 곡선, 최적 지점
- `[신규] L5-3` swap-set 분석. 스코어카드에서 GBM으로 교체 시 swap-in·swap-out 집단과 그들의 실제 부도율
- `[신규] L5-4` PD 구간별 금리표. 손익분기 금리 기반
- `[신규] L5-5` 한도 전략. PD 구간 × 소득 배수. 데이터 한계로 약식, 한계 명시
- `[신규] L5-6` 민감도: LGD, 금리, 비용률
- `[신규] L5-7` 공정성·수익 트레이드오프. 집단별 컷오프 변화에 따른 곡선.
  demographic parity, equalized odds, 집단별 보정의 동시 달성 불가를 곡선으로 제시
- `[신규] L5-8` 전략 평가 함수: (컷오프, 금리표) → 테스트셋 수익
- `[신규] L5-9` **RQ7.** 신뢰도 기반 라우팅 정책의 비용·효과.
  자동 / 혼합 / 인간검토 3구간, 검토 비용 대비 위반 감소

**완료 기준** 수익 곡선, 금리표, 트레이드오프 곡선, 민감도 범위.

## 6. 한계와 명시 사항

리포트와 발표에 반드시 쓴다. 모르고 넘어간 것보다 훨씬 좋게 읽힌다.

1. **시간 변수 부재.** Home Credit에 신청일이 없어 관찰기간·성과기간 설정,
   OOT 검증, 시점 간 PSI, vintage 분석이 불가능하다.
   분할 간·집단 간 PSI로 대체하며, 이는 대체재다
2. **거절 라벨 부재.** 승인된 신청만 성과가 관측되므로 reject inference는
   구조적으로 불가능하다. 개념만 기술한다
3. **손익 파라미터 부재.** 금리·LGD·비용률은 외부 가정이다.
   민감도 범위로만 제시하고 실제 수익으로 주장하지 않는다
4. **대안 데이터 제한.** 통신·소비·행동 데이터는 없다.
   금융 행태 데이터 범위 내 분석이다
5. **LLM 표본.** 본 실험 1종 300건, 파일럿 2종 50건. 사례 연구 수준이다
6. **SHAP 기준의 순환성.** L2-9 faithfulness로 방어하되,
   완전한 해소는 아니다
7. **보정과 SHAP.** TreeSHAP은 보정 전 log-odds 기준이다.
   보정은 단조변환이므로 변수 순위는 보존된다

## 7. 결론 틀

발표와 보고서에서 사용할 문장의 형태다. 숫자는 결과를 채워 넣는다.

**설명 검증**
- LLM 설명은 SHAP 상위 변수와 높은 수준으로 일치했고, 우연 수준을 넘어섰다
- 불일치는 특정 유형이 가장 많이 관찰되었으며, 그 비율은 집단별로 차이를 보였다
- 특정 집단에서 불일치가 더 자주 나타났으며, SHAP 집중도와 부도확률을 통제한 뒤에도 유지되었다

**신규 확장**
- 컷오프 근처에서 설명 일치도가 떨어지는 경향이 관찰되며, 설명 신뢰도와 의사결정 지점이 연결된다
- 일부 사례에서 보호변수가 사유로 언급되었으며, 법적으로 사용할 수 없는 정보를 참조할 위험이 있다
- 신뢰도 기준으로 설명을 분리하거나 검토 경로를 구분하면, 설명 품질과 비용의 균형을 제어할 수 있다
- 결과 요약과 그룹 비교를 통해 공정성 이슈와 설명 불일치의 연결 구조를 확인할 수 있다

앞의 내용은 측정이고, 뒤의 내용은 의사결정 및 실무 적용이다.
