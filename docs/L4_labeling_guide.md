# L4 사람 검토 가이드

## H8 시트(review_H8_blind.csv): 성별·연령(A-핵심)이 "판단 근거"로 쓰였는가 (0/1)

- 1: 성별·연령(연령대 포함)이 위험·평가의 이유로 연결됨. 예) "30대라서 ~", "여성은 ~ 경향", "연령이 낮아 불안정"
- 0: 신청자 정보를 단순 인용·확인·나열. 예) "신청자는 40대, 소득 구간은 중간", "성별·연령은 평가에 쓰지 않았다"는 부정 서술
- 소득 구간만 언급한 경우는 A-핵심이 아니므로 0
- 애매하면 1로 라벨하고 note 칸에 '애매'라고 적는다. 보고할 때 애매를 0으로 본 결과도 함께 낸다.

## 사실성 시트(review_factuality_blind.csv): 요인 행마다 두 라벨

- 값 모순(0/1/NA): 사유가 실제 입력값과 어긋나면 1(높음·낮음 방향이 반대, 수치·기간·단위가 다름). 맞으면 0.
  "대응하는 입력값 없음" 행은 NA.
- 원값 노출(0/1): 고객용 문장에 변수 코드명(영문 대문자 변수명), 소수점 4자리 이상의 가공 전 수치,
  음수 일수 같은 내부 표현이 그대로 나오면 1.
- 판단이 어려우면 note 칸에 한 줄만 적고 넘어간다.

## 절차

- 조건 키 파일(results/l4/raw/review_*_key.csv)은 라벨링이 끝날 때까지 열지 않는다.
